## Day 2 – Variables & Data Types 🧠

### Objective
Understand basic Python data types and how to store and use values in variables.

---

### Topics Learned
- Variables
- `int` (Integer)
- `float` (Decimal Numbers)
- `str` (String/Text)
- `bool` (Boolean – True/False)
- Type Conversion (`int()`, `str()`, `float()`)

---

### Practice Tasks

2. Create variables for:

  - Age
  - Height
  - Is Student (True/False)

4. Convert string number to integer
5. Swap two variables
6. Simple interest calculator
